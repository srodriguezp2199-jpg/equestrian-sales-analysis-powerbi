# 📂 Datos del proyecto

Esta carpeta contiene la base de datos utilizada para desarrollar el proyecto **Análisis de Ventas del Sector Ecuestre | Power BI**.

## Archivo

`Ventas_aperos_Github.xlsx`

La base contiene **345 registros de ventas correspondientes al primer semestre de 2026**.

Durante la preparación de los datos se realizaron procesos de:

- Limpieza de datos.
- Estandarización de clientes y productos.
- Corrección de inconsistencias.
- Clasificación de productos por categorías.
- Consolidación de **44 referencias originales en 25 productos estandarizados**.
- Preparación de los datos para su análisis en Power BI.

## 🔒 Privacidad y anonimización

El proyecto original fue desarrollado utilizando información de una empresa real.

Para publicar este proyecto como parte de mi portafolio, la base de datos fue **anonimizada** con el objetivo de proteger la información de la empresa y de sus clientes.

Los nombres, correos e identificadores de clientes fueron reemplazados por valores ficticios.

La estructura de los datos y la lógica utilizada para desarrollar el análisis se conservaron para mantener la integridad del proyecto.

## Uso de los datos

Esta versión del dataset se publica exclusivamente con fines de **portafolio y demostración del proceso de análisis de datos**.
