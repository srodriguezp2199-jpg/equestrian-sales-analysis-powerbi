# 📊 Dashboard de Power BI

Esta carpeta contiene el archivo `.pbix` correspondiente al proyecto **Análisis de Ventas | Power BI**.

## Archivo

`Sales_Performance_Analysis.pbix`

El dashboard fue desarrollado en **Power BI Desktop** y contiene dos páginas de análisis orientadas al seguimiento del desempeño comercial.

### Principales KPIs

- Revenue Total
- Ticket Promedio
- Total de Pedidos
- Variación mensual de ventas (%)

> **Nota:** El archivo utiliza una versión anonimizada de los datos originales para proteger la información de la empresa y sus clientes.

Para visualizar el dashboard sin descargar el archivo `.pbix`, consulta las capturas incluidas en el README principal del repositorio.
